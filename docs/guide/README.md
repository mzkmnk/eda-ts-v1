# イベント駆動アーキテクチャ（EDA）学習ガイド

TypeScript + AWS + LocalStack を使って、イベント駆動アーキテクチャを実践的に学ぶための学習ガイドです。

## 概要

このガイドでは、**オンライン注文処理システム**を題材に、EDA の基礎から本番運用までを段階的に学びます。

│  │  (注文)   │    └─────────────┘    │      (イベントバス)               │   │

## 前提条件

- Node.js 20.x 以上
- Docker Desktop
- TypeScript の基本的な知識
- AWS の基本的な知識（S3、Lambda 程度）

## クイックスタート

```bash
# リポジトリのクローン
git clone <repository-url>
cd eda-learning

# 依存関係のインストール
pnpm install

# LocalStackの起動
docker compose up -d

# CDKのブートストラップ
npx cdklocal bootstrap

# デプロイ
npx cdklocal deploy
```

## 各ステップの構成

各学習ガイドは以下の構成になっています：

1. **目標** - 達成すること
2. **背景情報** - 概念や技術の説明
3. **メリット・デメリット** - トレードオフの理解
4. **コードサンプル** - 実装例
5. **課題** - 実践的な演習
6. **ヒント（アコーディオン）** - 課題のヒント
7. **回答（アコーディオン）** - 課題の解答
8. **確認クイズ** - 理解度チェック
